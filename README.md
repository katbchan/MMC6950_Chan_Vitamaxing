# Vitamaxing - Supplement Manager

## Overview
A web application that will provide users with a simple way to organize and manage information about supplements they are currently taking or considering. The application will allow users to search for supplements, view product and ingredient information, add supplements to a personal list, and identify overlapping ingredients among the supplements on that list.

## MVP
**Core Features:**
- Supplement Search (NIH DSLD API): Search for supplement products by name, results will display available products and details.
- Supplement Management (CRUD): View detailed supplement information and personal supplement lists, add and remove supplements, and edit personal lists.
- Authentication: Create an account and log in.
- Ingredient Overlap Detection
- Overlap Warnings

**Nice-to-Have Feature:**
- Supplement timing and scheduling

## Technologies
- Next.js / React
- MongoDB
- NIH Dietary Supplement Label Database (DSLD) API
- Authentication
